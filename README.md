# Full Stack Open - Exercise 21

A phonebook application with a React frontend and an Express backend.

## Frontend

- Install dependencies: `npm ci`
- Run lint: `npm run lint`
- Build: `npm run build`

Directory: `app/frontend`

## Backend

- Install dependencies: `npm ci`
- Run tests: `npm test`

Directory: `app/backend`

## Continuous Integration

GitHub Actions runs frontend linting, frontend build checks, and backend tests on pushes and pull requests targeting main.
